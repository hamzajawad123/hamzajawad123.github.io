## 💻 Local Development & Preview

To preview the website locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/hamzajawad123/hamzajawad123.github.io.git
   cd hamzajawad123.github.io
   ```

2. **Start a local HTTP server** (using Python):
   ```bash
   python -m http.server 8000
   ```

3. **Open in browser**:
   Navigate to [http://localhost:8000](http://localhost:8000) to view the live site.
