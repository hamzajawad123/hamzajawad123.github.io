Binance Crypto Volatility Predictor

Local-First MLOps Pipeline for 24-Hour Forward Volatility Across 4 Major Crypto Assets

Project Overview

Cryptocurrency markets operate 24/7 with non-stationary volatility clusters and rapid regime shifts. Accurately quantifying 24-hour-ahead forward volatility is essential for dynamic risk management, position sizing, and derivatives valuation. This project develops a local-first MLOps pipeline forecasting forward volatility for 4 leading cryptocurrency assets: Bitcoin (BTC), Ethereum (ETH), Binance Coin (BNB), and Solana (SOL).

19% Error Reduction vs Baseline 4 Core Crypto Assets 24h Forward Horizon

Objectives

  • Ingest and process granular OHLCV price feeds from the Binance API.
  • Engineer domain-specific financial volatility features (Garman-Klass, Parkinson, Exponentially Weighted Moving Average volatility).
  • Train robust gradient boosted models (LightGBM and XGBoost) capable of learning asymmetric volatility response.
  • Maintain full experiment tracking with MLflow and deploy a lightweight local-first FastAPI prediction engine.

Engineering & Pipeline Details

  1. Financial Feature Engineering:

    Constructed rolling log-returns, realized volatility over multiple historical windows (1h, 4h, 12h, 24h, 7d), cross-asset correlation features, and volume momentum indicators to capture volatility clustering.

  2. Model Architecture & Experimentation:
    • Tuned hyperparameter spaces for LightGBM and XGBoost using rolling time-series cross-validation to prevent forward-looking data leakage.
    • Tracked all experiments, metrics (RMSE, MAE, MAPE), and model artifacts using MLflow.
  3. Benchmarking Against Persistence:

    Compared predictions directly against a naive persistence baseline (yesterday's realized volatility = tomorrow's volatility) and classical GARCH(1,1) benchmarks.

  4. API Serving:

    Implemented a clean REST API using FastAPI enabling programmatic retrieval of 24h volatility forecasts and risk percentiles for all 4 assets.

Key Verified Results

  • Achieved a 19% reduction in forecast error (RMSE) compared to the naive persistence baseline.
  • Demonstrated consistent predictive power across all 4 evaluated assets (BTC, ETH, BNB, SOL) across differing market volatility regimes.
  • Constructed a modular, reproducible local MLOps pipeline ready for real-time streaming integration.

What This Project Demonstrates

Practical competence in quantitative time-series engineering, baseline-oriented machine learning validation, MLflow lifecycle management, and production-ready API development.
