E-Commerce Churn & LTV Predictor

Two-Model Production MLOps Pipeline with Feast Feature Store & CatBoost

Project Overview

In modern e-commerce, retaining existing customers is dramatically more cost-effective than acquiring new ones. However, treating all at-risk customers equally leads to wasted marketing budgets. This project implements a two-model production MLOps pipeline designed to simultaneously predict churn risk and estimate prospective Customer Lifetime Value (LTV) across 50,000 customer transaction records.

+16% Holdout ROC-AUC Feast Feature Store 50,000 Records Processed

Objective

  • Eliminate train-serve skew by establishing a standardized, centralized feature definition layer with Feast.
  • Train multi-objective models: a binary classifier for churn likelihood and a continuous regressor for forward LTV estimation.
  • Track model experiments and parameters via MLflow to select champion models objectively.
  • Serve low-latency inference through a modular FastAPI service and provide operational visibility via a Streamlit application.

Technical Architecture & Implementation

  1. Feature Store Architecture with Feast:

    Defined reusable customer entities and feature views covering RFM metrics (Recency, Frequency, Monetary value), historical return rates, cart abandonment ratios, and discount sensitivity. Feast ensured consistency between offline batch training and online real-time inference.

  2. Model Development & Tuning:
    • Compared multiple architectures including Logistic Regression, Random Forest, XGBoost, and CatBoost.
    • CatBoost handled categorical user segments and high-cardinality geographic features effectively without manual one-hot explosion.
  3. Experiment Tracking with MLflow:

    Logged hyperparameter grids, precision-recall curves, ROC curves, and feature importances into MLflow for full reproducibility and artifact registry.

  4. Deployment & Serving:

    Exposed scoring endpoints via FastAPI, allowing CRM systems to query churn probabilities and estimated lifetime values in real time, backed by an intuitive Streamlit interface.

Key Verified Results

  • The CatBoost champion model improved holdout ROC-AUC by 16% over the baseline statistical benchmark.
  • Seamless online feature retrieval with sub-50ms latency using Feast feature definitions.
  • Delivered dual-axis customer segmentation: prioritizing proactive retention outreach toward high-LTV, high-churn-risk segments.

What This Project Demonstrates

This project showcases modern production machine learning architecture: feature store integration, multi-model operational pipelines, model experiment tracking, and clean API design to deliver quantifiable business value.
