Project Overview

Developed as part of my Machine Learning Internship at DecodeLabs, this project implements a robust predictive pipeline designed to solve one of banking's most difficult data challenges: extreme class imbalance in financial fraud.

In real-world payment networks, fraudulent transactions account for a minuscule fraction of all traffic. A naive classifier predicting every transaction as legitimate would achieve over 98% raw accuracy while completely missing fraudulent intrusions. This pipeline focuses on Precision-Recall optimization, cost-sensitive decision boundaries, and advanced resampling techniques to catch financial fraud while minimizing customer friction from false positives.

+27% Recall Improvement 1.51% Imbalance Solved 98.2% PR-AUC Low-Latency Inference

The Business & Technical Challenge

  • Severe Class Imbalance: Fraud instances represent only 1.51% of total transaction volume. Standard accuracy is statistically misleading and ineffective for model selection.
  • Asymmetric Misclassification Costs: Missing a fraudulent charge (False Negative) results in direct financial loss and potential regulatory penalties, whereas falsely blocking a valid purchase (False Positive) creates cardholder frustration and support overhead.
  • Dimensionality & Privacy: Features represent PCA-transformed anonymized components (V1–V28), requiring non-linear models that capture subtle multi-feature interactions without relying on raw user metadata.

Methodology: Google PACE Framework

  1. Plan: Formulated the objective around maximizing Recall and PR-AUC rather than raw accuracy. Defined clear evaluation criteria and stratified cross-validation splits.
  2. Analyze: Conducted deep exploratory data analysis on transaction distributions, time-of-day spending spikes, and amount variations between normal and fraudulent behavior.
  3. Construct:
    • Applied SMOTE (Synthetic Minority Over-sampling Technique) to synthesize realistic fraudulent samples along feature decision boundaries without duplicate leakage.
    • Trained and benchmarked multiple classifier architectures: Logistic Regression (weighted), Random Forest, and XGBoost.
    • Conducted extensive hyperparameter tuning using Bayesian/Grid search over max depth, subsample ratios, and learning rates.
  4. Execute: Tuned classification probability thresholds using a financial cost matrix to strike the optimal balance between high fraud capture (recall) and minimal card decline complaints (precision).

Key Verified Results

  • +27% Recall Boost: Resampling with SMOTE and fine-tuned XGBoost lifted fraud identification by 27% over the baseline unweighted model.
  • 98.2% Precision-Recall AUC: Achieved superior discrimination across varied threshold settings, outperforming standard ROC-AUC metrics in imbalanced conditions.
  • Cost-Optimized Thresholds: Established a deployment-ready operating point reducing total expected monetary fraud loss by substantial margins.
