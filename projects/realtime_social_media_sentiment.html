Real-Time Social Media Sentiment Pipeline

Distributed Streaming with Apache Kafka, PySpark Structured Streaming & Multi-Class ML

  1. Home
  2. Projects
  3. Real-Time Social Media Sentiment

Project Overview

Online public discourse moves at conversational velocity. Organizations monitoring brand reputation, crisis response, or trending events cannot wait for nightly batch jobs. This project establishes a distributed real-time streaming pipeline using Apache Kafka and PySpark Structured Streaming to ingest high-velocity tweet streams and classify sentiment on the fly.

89% ML Accuracy +14% Accuracy over Baseline 500 Tweets / Run Ingestion

Objectives

  • Establish a fault-tolerant message streaming ingest layer using Apache Kafka topics.
  • Process streaming JSON payloads in micro-batches with PySpark Structured Streaming.
  • Extract distributed TF-IDF and n-gram lexical features across cluster workers.
  • Train and evaluate a 4-class sentiment classifier (Positive, Negative, Neutral, Irrelevant) capable of low-latency distributed inference.

Pipeline Architecture

  1. Stream Producer Layer (Kafka):

    Simulated and published continuous live text streams (500 tweets/run) into partitioned Kafka topics with key-value schema validation.

  2. Streaming Ingestion (PySpark Structured Streaming):

    Subscribed to Kafka topics, deserialized binary strings into structured Spark DataFrames, and handled backpressure and checkpointing for fault-tolerant recovery.

  3. Distributed NLP Preprocessing:

    Executed regex tokenization, stop-word removal, and HashingTF / IDF vectorization across worker partitions to prepare numeric features at scale.

  4. Machine Learning Inference:

    Trained and served a 4-class machine learning classification model on the streaming DataFrame, outputting scored sentiment streams directly to analytical sinks.

Key Verified Results

  • Trained a 4-class classifier reaching 89% accuracy on live text evaluation.
  • Improved overall classification accuracy by 14% over baseline heuristic models.
  • Maintained sub-second micro-batch latency from Kafka topic ingestion through PySpark ML scoring.

What This Project Demonstrates

Hands-on expertise in Big Data streaming engineering, distributed compute with PySpark, message-queue architecture with Kafka, and real-time machine learning inference.
