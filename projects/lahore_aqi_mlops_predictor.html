Project Overview

During my Data Scientist Internship at 10Pearls (Jul 2026 – Sep 2026), I developed and deployed an automated, production-grade MLOps pipeline to forecast Lahore's Air Quality Index (AQI) across multiple forward horizons: 24, 48, and 72 hours. Air pollution in Lahore is a severe seasonal public health challenge; accurately anticipating spikes enables health advisories, urban planning interventions, and public awareness.

+18% Forecast Accuracy 22% RMSE Error Reduction 65% Pipeline Uptime Boost

Objectives & Challenges

  • Multi-Horizon Forecasting: Predict continuous AQI values at 24h, 48h, and 72h lead times rather than just static 1-step-ahead forecasts.
  • Persistence Baseline Challenge: Air quality exhibits heavy temporal auto-correlation. In production, a machine learning model is useless unless it reliably beats a naive persistence baseline (assuming tomorrow will be the same as today).
  • Full MLOps Lifecycle: Move beyond local Jupyter experiments to a self-contained system featuring experiment tracking, automated model evaluation gates, containerization, and scheduled re-training.

Technical Approach & Pipeline Architecture

  1. Data Ingestion & Cleaning: Ingested historical meteorological and atmospheric readings for Lahore, handling sensor gaps, extreme outliers, and missing time intervals.
  2. Feature Engineering: Engineered rolling moving averages, exponential lag variables (1h, 6h, 12h, 24h, 48h, 72h), diurnal temperature differentials, wind dispersion metrics, and temporal cyclic sine/cosine calendar encodings.
  3. Model Exploration & Registration:
    • Trained and tuned gradient boosted ensembles (LightGBM, XGBoost) and additive time-series models (Facebook Prophet).
    • Implemented strict validation gates: models were only registered if they beat the naive persistence baseline on RMSE, MAE, and R² metrics across holdout folds.
  4. Containerized Serving & UI:
    • Built a lightweight, asynchronous FastAPI backend providing REST inference endpoints for automated scoring.
    • Developed an interactive Streamlit web dashboard visualizing multi-horizon predictions with confidence bounds.
    • Containerized the complete application stack with Docker for reproducible deployment.
  5. CI/CD & Automation: Automated testing, linting, and scheduled data update runs using GitHub Actions.

Key Verified Results

  • +18% Accuracy Improvement over the naive persistence baseline across test horizons.
  • 22% RMSE Reduction in forecast error, clearing the production validation gate.
  • 65% Improvement in Pipeline Uptime achieved through containerized microservices and automated GitHub Actions workflows.
